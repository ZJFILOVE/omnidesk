# 播放性能更新（2026-10-10）

- AI 阅读栏仅在数据变化时更新章节、问答与文字布局，减少高刷新率播放时的 CPU 开销。
- 进度条广告标记不再逐帧复制完整助手资料。
- 桌面新配置默认开启自动硬解；保留已保存的硬解开关。
- Ctrl+F3 增加实际硬解方式及解码／输出丢帧统计，使用异步属性通知；显示倍速所需帧率和屏幕刷新率，提示超出显示上限的情况。
- 增加独立配置下的原生播放性能基准，区分 CPU 占用、解码和播放推进。

# wiliwili AI 3.0.0（2026-10-05）

基于 wiliwili 1.6.0（88e5876bea95），继续使用 GPL-3.0。

- 修复搜索输入法候选框：Hyprland 启动时使用 XWayland 兼容后端，保留显式 SDL 后端设置；输入法仅在编辑器内启用，缩放和全屏切换后更新候选框坐标。加入真实 Fcitx / Rime 候选窗口及中文选词验证。
- 原生 B站登录与高清播放授权：二维码、扫码确认、有效期、过期刷新、取消、错误重试、会话检查、刷新和退出。已批准会话优先复用，验证两个会话的账号一致性。
- C++ Android PlayViewUnite trial 取流用于普通视频的正式播放、分 P、合集与画质选择；失败继续普通网页 / HTML5 流。保留编码、HDR 和音轨偏好，拒绝不完整视频。
- 播放请求和字幕、弹幕、快照增加视频 / 分 P / 账号身份校验；取消旧 Android 请求。媒体加载失败可退回普通流。
- 退出账号立即清空历史、收藏和动态内容；个人资料与列表的迟到响应不会恢复旧账号内容。
- Ctrl+F3 展示 libmpv 异步观察到的实际媒体信息。当前清晰度显示编码尺寸，加载中的菜单质量不会作为实际清晰度。
- 凭据在仓库外按 0600 原子保存。去除原始响应、签名媒体 URL 与请求头日志。
- 保留原生首页、搜索、用户页、收藏、历史、桌面快捷键、全屏和 AI 阅读栏。本机模型接口与已有模型配置继续使用。
- 发行包与完整 GPL 源码包、构建信息、校验和以及先备份再替换的安装器。日常使用无需 Android 容器、ADB、Frida 或授权脚本。

高清取流依赖服务端当前 trial 策略，不保证所有视频或永久有效。真实服务和独立测试结果见源码工作区 `validation/release-3.0-*.json`；它们不随运行包分发。
