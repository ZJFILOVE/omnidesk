# 伴读 · 书与语境（EPUB / MOBI 电子书伴读）

围绕**英文原版电子书（EPUB / MOBI / AZW3 / TXT）导入与上下文深度伴读**构建的安卓与网页应用。接入飞牛 `8766` 端口的 `gpt-6-luna` 与美剧台词检索接口，并与手机输入法模块「措辞」共享同一端口与令牌。

---

## 核心设计逻辑

1. **多格式英文电子书导入（`.epub` / `.mobi` / `.azw3` / `.txt`）**
   - 纯前端内置 ZIP/EPUB2/EPUB3 解析器与 PalmDOC LZ77/EXTH MOBI 解析器，自动提取书名、作者、封面、栏目分组、章节目录以及自然段与英文分句。
   - 已导入的书籍保存在本机 `IndexedDB`（`ebook_companion_db`），随时切换阅读进度。

2. **沉浸式阅读与弹窗查询**
   - **章节内分页**：正文根据可用屏幕空间、字号自动排成单栏或宽屏双栏。阅读时只保留章节名、菜单和单行页码；书架、字号、进度滑块、章节跳转与其他功能集中在阅读菜单。
   - **直接点词查词**：默认点按正文单词打开查询弹窗，携带当前原句和章节，点击「AI 查询词义与词源」查看语境释义、词源与同根词。页顶「点词查词／点句解读」可切换并记住偏好；长卷模式在阅读菜单切换。句子弹窗也会完整提取单词（含短词），不再只列出前 20 个。查词弹窗关闭后停留原页，键盘翻页不会穿透弹窗。
   - **书内点句即读**：点按句子自动结合前一段、当前段与后一段查询，用独立弹窗展示结果、朗读、段落译注及单词查询；关闭后保持原页。正文不会因查询结果或段落译注而被挤压或重新分页。
   - **安卓系统选词与分享**：`ACTION_PROCESS_TEXT` / `ACTION_SEND` 传入的文本直接弹窗查询。应用不读取剪贴板，也不在切回应用时检查剪贴板；仍可主动复制查询结果。
   - **阅读操作**：左右滑动、底部箭头或键盘方向键翻页，章末自动进入下一章。点击页码打开进度菜单；可切换到长卷精读。
   - **多维解读预设与自由追问**：支持组合「结合上下文深读」「长难句拆解」「地道表达与词源」「人文与背景典故」，并可输入任意补充追问。

3. **从阅读中生长的笔记与书中生词本**
   - 所有解读过的句子连同原书章节段落位置自动存入「句段解读笔记」，随时一键跳回原书对应段落。
   - 点击句中任意单词即可查看它在你已导入电子书中的所有真实原句、让 `6-luna` 拆解语境词义与词根词源、加入生词本并用 SM-2 闪卡复习，或一键检索美剧真实对白。

## 阅读查词回归验证

- `node --test tests/readerWords.test.ts`：标点与空格保留、缩写／连字符、短词及超过 20 个单词的提取。
- `npm run build` 后，使用安装了 Playwright 和 Chromium 的 Python 运行 `python tests/reader_lookup.py`。脚本自行启动仅本机可访问的测试页面，用合成书籍和模拟 AI 响应验证手机／宽屏下的直接点词、原句传递、语境缓存、错误重试、弹窗关闭后的页码与键盘、触屏翻页、句中单词提取及长卷模式，不访问真实模型。
