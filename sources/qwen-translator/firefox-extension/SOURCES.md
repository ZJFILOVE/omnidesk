# Source and design references

This extension is an original implementation written for the Qwen translator project.
No Read Frog source files, assets, prompts, or dependencies are included in this bundle.

Read Frog (陪读蛙) was reviewed as a design reference for paragraph discovery,
preserving inline HTML, batching, and viewport-driven translation:
https://github.com/mengxi-ream/read-frog/tree/784a6f016fbd3fbe7fd3e671e2b94a8cdc9dddab

The reviewed upstream project uses GPL-3.0 and a commercial license. If code is
copied from it in a future change, include the applicable license and attribution
and review the resulting distribution requirements at that time.

Firefox API reference: https://developer.mozilla.org/en-US/docs/Mozilla/Add-ons/WebExtensions
