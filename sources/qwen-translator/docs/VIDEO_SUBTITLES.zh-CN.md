# 视频字幕：本地 / 飞牛 / YouTube

原生应用侧栏的 **视频字幕** 页支持直接加载已有字幕，也可识别、翻译和校准后观看。视频不烧录字幕，不重新压制；字幕、翻译缓存和下载文件保存在项目 `video-cache/`。

Radarr / Sonarr 入库后的批量自动化请使用新增 **NAS 自动字幕** 页：复用本页的 SubHD / ASSRT 下载、文本字幕处理、ASR 和翻译，最终输出中英对照 SRT，支持持久队列和受保护 NAS 写回。详见 [NAS 自动字幕说明](NAS_SUBTITLES.zh-CN.md)。该页采用独立的 `nas-cache/` 版本与输出归属记录；手动处理方式不变。

## 按标题重新打开缓存视频

在 **打开视频 → 已缓存视频** 中按标题选择，或输入标题关键词筛选，再点 **打开所选视频**。列表按最近完成字幕的时间排序，自动读取已有缓存，重启应用后仍可使用，不需要再粘贴链接或寻找本地路径。

打开后恢复上次成功加载或准备的字幕，点击 **播放** 即可观看；有双语版本时默认使用双语。已下载的 YouTube 视频直接复用本地文件，在线播放的缓存仍需联网，本地 / 网盘视频仍需原文件可访问。打开缓存不会重新下载、识别或翻译。文件缺失、变更或损坏时会提示重新检查或准备。

字幕任务结束和清理缓存后列表自动更新，也可点击 **刷新列表**。删除字幕缓存会移除对应列表记录；仅删除下载视频会保留字幕记录，但需重新准备视频才能恢复本地播放。同名视频保留各自记录，并显示来源以便区分。

## 本地视频：加载与保存

- **已有匹配字幕**：选择视频后，用 **导入字幕 / ZIP** 选择单个 SRT、ASS、SSA 或 VTT，会直接加载并启用 **播放**。也可先检查视频，在列表中选择同名外挂字幕或内嵌文本字幕，再点 **加载所选字幕**。ZIP/GZIP 中可能有多集，需要先在列表选中对应字幕再加载。
- **加载保持原时间轴**：字幕复制到本机缓存；ASS/VTT 转成标准 SRT，不保留 ASS 特效。直接加载不触发语音识别、翻译、自动对齐或手动偏移，不需要配置翻译服务。
- **英文字幕翻中文**：加载英文字幕后，保留勾选 **生成中文字幕**，点 **准备 / 翻译中文字幕**。默认使用偏好设置里的 Codex 模型，直接翻译字幕文字，不再识别音频；自动中文判断不准确时可选“没有中文，翻译为中文”。原文、中文和双语版本分别保留。
- **加载回播放器**：同一视频已由应用启动且 mpv 控制连接建立时，新字幕完成后会自动切换进去，播放位置不变。尚未播放时点击播放；其他播放器通过启动参数加载字幕。
- **时间轴校正保留**：字幕与片源不匹配时，选择自动 / 分段对齐、参考字幕、整体偏移或倍率，再准备字幕。先校正原文时间，翻译保持校正后的每条时间戳，另保留未经校正的原始字幕。仅需校正时取消勾选中文，按钮变为 **准备原字幕**。
- **保存字幕**：选择要保存的字幕版本，点 **保存字幕 SRT…**。本机视频默认建议保存在视频同目录；网盘或可移动挂载路径先打开主目录，避免打开窗口时等待挂载响应，可手动选择保存位置。中文为 `视频名.zh.srt`，双语为 `视频名.bilingual.srt`，处理后原文为 `视频名.source.srt`，未经处理或直接加载的字幕为 `视频名.original.srt`。这些文件下次检查视频时会被发现，也可手动导入。
- **保留已有文件**：保存前显示文件对话框，遇到同名文件会询问是否覆盖。只读 NAS 可在对话框选择本机目录；加载和准备不改写视频或原字幕文件。保存后也能在其他播放器中手动加载这个 SRT。

## 使用

1. 选择本地视频或网盘挂载里的视频，也可粘贴 YouTube 链接。点 **检查视频** 获取音轨、内嵌文本字幕和同名外挂字幕。
2. 需要网站字幕时，修改搜索词为剧名和季集，例如 `Stranger Things S02E01`，点击 **搜索字幕**，核对片源后 **下载所选字幕**。一包包含多集时，在准备字幕下拉框中选择对应集。
3. 也可用 **导入字幕 / ZIP** 选择 SRT、ASS、SSA、VTT 或含文本字幕的 ZIP/GZIP。ASS/VTT 会转成 SRT；不保留 ASS 特效。RAR 需要自行解压后导入。
4. 没有外部字幕时，自动选择已有中文字幕，再考虑其他字幕；都没有时本地 ASR。可指定音轨或内嵌字幕。“使用本地识别”忽略现有字幕并继续上次识别进度；“从头重新识别”重建识别检查点，保留之前已生成的字幕成品。重做后中断会从新检查点续做。
5. 勾选 **生成中文与原文对照字幕**：已有中文则保留；否则复用偏好设置里的翻译服务，按视频时间每约 10 分钟一批翻译（字幕文字特别密集时再拆分）。在 **偏好设置 → 视频 / 网页翻译并发** 中选择 1–8 个任务，默认 4；较短视频也会拆分较大的批次以便并行，小批次保留上下文。模型返回带编号的译文，程序按原时间戳排序并生成 SRT；缺号、重号或条数异常时自动缩小该段重试，已成功的部分立即缓存续做。单次模型调用最长等待 10 分钟。自动中文判断可手动覆盖。已有双语字幕会保留双语内容。

并发上限分别作用于单个视频任务和网页服务，同时使用两者时请求数会相加。Codex 限流时，同一任务池暂停新请求并逐步延长等待，最多调用三次；额度耗尽时停止待执行请求，额度恢复后重新运行任务或重启网页服务。取消或失败会清理未完成任务，成功缓存保留。
6. 选择时间轴处理方式，点 **准备 / 翻译中文字幕**（关闭中文时为 **准备原字幕**）。完成后选择字幕版本，点击 **播放** 或 **保存字幕 SRT…**。再次检查相同视频会恢复上次成功加载或准备的结果。

本地文件包括已挂载的 SMB/WebDAV/NFS 路径。当前飞牛使用 Tailscale + SMB，旧剧集可从 `/mnt/feiniu-smb/serial` 选择，新电影 / 剧集库位于 `/mnt/feiniu-smb/media-library/movies` 与 `tv`。原 `/mnt/feiniu` WebDAV 入口仍保留；自动字幕优先使用已通过防覆盖写回测试的 SMB 路径。只读挂载也可用，输出留在本机；首次扫描或提取内嵌字幕可能需要较多网络读取。

文件窗口使用 Qt 列表视图并关闭自定义目录图标查询。首次打开从主目录开始；上次目录属于网盘或可移动挂载时也回到主目录，不自动访问该挂载。可在文件名栏输入 `/mnt/feiniu-smb/serial/` 进入网盘，或直接在视频路径框粘贴完整文件路径。手动进入网盘后的列目录速度仍取决于网络和挂载状态。目录图标查询在网络盘上可能造成明显性能问题，参见 [Qt QFileDialog 文档](https://doc.qt.io/qt-6/qfiledialog.html#Option-enum)。

## SubHD 当前下载流程（2026-09-14 实测）

SubHD 的公开页面脚本采用两步下载：

1. 在 `/a/<字幕ID>` 详情页点击下载，页面向 `/api/sub/prepare-download` 发送字幕 ID。
2. 成功后进入临时 `/down/<字幕ID>` 页面，再点下载，由页面向 `/api/sub/down` 请求文件地址。
3. 浏览器取得字幕文件。

对 `kAPF5K` 条目，独立、未登录的 Chromium 会话实际完成了两次点击和下载，没有要求手工输入验证码。直接 HTTP 请求曾被拒绝，不能据此推断必须登录，也不能保证所有条目和网络环境都免验证。

应用使用 Playwright 启动临时浏览器，正常操作这两步，完成后关闭。没有借用日常浏览器的 Cookie 或密码，也不绕过验证码。若站点要求登录或人工验证，应用提示打开原网页完成，再导入字幕；当前没有保存 SubHD 登录会话的功能。

这不是 SubHD 的官方开放 API，页面结构变化可能影响自动下载。来源：[SubHD 详情页](https://subhd.tv/a/kAPF5K)、[公开页面脚本](https://subhd.tv/public/js/subhd.js)。

## ASSRT

已实现官方 API 的搜索、详情及文本字幕下载，需要个人 Token。可在本页输入，通过系统密钥库保存、读取或清除；Token 不写入 QSettings 或字幕缓存。

字幕服务由 [assrt.net](https://assrt.net/) 提供。接口与 Token 申请说明见 [ASSRT API 文档](https://assrt.net/api/doc)。本次没有可用 Token，未进行真实账户下载验证。

## 时间轴校准

- **同片源参考优先**：视频里已有英文文本字幕时，用它作为外挂中文的参考。也可手选一个已同步的参考 SRT。对齐利用字幕出现的时间模式，不要求中英文逐句翻译一致。
- **没有参考字幕**：分析所选音轨的语音活动，使用 ffsubsync 求时间偏移和速率差异。
- **固定偏移**：整体偏移可手动设定，正值表示字幕延后。
- **逐渐漂移**：时间倍率可修正速率差异，例如部分帧率转换导致的漂移。
- **片头、广告或剪辑差异**：选择分段对齐，使用 ffsubsync 0.5.1 的分段偏移模式。无法补回缺失字幕，也不能保证修复不同剪辑版本。

自动对齐的低质量结果会被拒绝，并提示改选字幕或手工校准。成功结果仍是待观看核对的候选，应抽查开头、中间和结尾；不能把算法成功等同于人工逐句确认。原始字幕与各次准备结果分开保存。

来源：[ffsubsync](https://github.com/smacke/ffsubsync)；另调研了 [alass](https://github.com/kaegi/alass)，当前未引入第二套运行时。

## 播放器

- **mpv**：已接入独立窗口和 JSON IPC，支持播放位置显示、暂停、前后跳转、倍速和切换字幕版本。退出应用会关闭由应用启动的播放器。
- **mpv 声音输出**：使用 **设备与音频 → 声音输出设备** 中选定的设备，避免系统默认输出为 Sunshine 或会议虚拟声卡时听不到视频声音。更换设备后重新点击 **播放** 生效；尚未选择设备时沿用播放器默认输出。上方“识别 / 对齐音轨”只决定字幕处理使用哪条音轨。
- **VLC / SMPlayer**：已实现启动时传入外挂字幕的参数适配；播放操作使用播放器自己的窗口。这两个适配器目前仅检查参数，尚未在本机安装并运行验证。
- **Haruna / Celluloid 等**：可导出标准 SRT 手动加载；没有声称支持远程控制这些播放器。

当前不提供“翻译一小段就开播”的后台增量播放，也没有内嵌播放器。已经完成的字幕交给播放器按媒体时间显示，因此暂停和倍速不会改用模型返回时间。

## YouTube

优先取得可用的中文 / 英文字幕，再考虑英文自动字幕；没有时下载音轨后 ASR。默认下载最高 1080p 视频后本地播放，也可关闭下载视频、使用在线播放。仅下载音轨不等于可以离线观看画面。

- **只取原字幕**：粘贴链接后点击 **获取原字幕（不翻译）**。有平台字幕时下载并转换为 SRT；没有字幕才下载音轨做 ASR。这个操作不读取文本翻译配置、不调用 Codex，也不应用偏移、倍率或自动对齐。
- **只需导出时**：关闭上方“YouTube 下载视频后播放”选项。有可用字幕时不下载媒体；没有字幕时仅下载识别所需音轨。保留勾选则同时准备本地播放的视频。
- **下载进度**：视频和音轨分别显示当前下载百分比、已下载大小、速度和预计剩余时间。无法确定总大小时显示等待动画与已下载大小；合并音视频时显示“正在合并音视频”，之后继续准备字幕。下载期间可取消，已下载的部分保留供重试续传。
- **翻译中文**：点击 **准备 / 翻译中文字幕**，英文人工字幕或自动字幕直接调用文本翻译；没有字幕时先 ASR 再翻译。平台字幕保留原时间轴，不因它是外部下载文件就自动重新对齐。
- **跳过平台字幕做 ASR**：在字幕来源中选择 **使用本地识别（继续上次进度）**，再获取原字幕或准备中文。即使平台有自动字幕，也会使用下载的媒体识别；需要重新识别时选择 **从头重新识别（忽略上次识别进度）**。媒体下载本身仍需成功。
- **独立导出**：在“播放与保存”中选择原字幕、中文或双语，再点击 **保存字幕 SRT…**。原字幕会标注“YouTube 上传字幕”“YouTube 自动字幕”或“本地 ASR 识别原文”，不需要先翻译为中文才能保存。
- **文件名区分来源**：原稿默认建议 `标题.youtube_manual.original.srt`、`标题.youtube_auto.original.srt` 或 `标题.asr.original.srt`；中文、双语分别使用 `.zh.srt`、`.bilingual.srt`。导出的是标准 SRT，保留该版本的文本和时间戳，不保留平台 VTT 的排版元数据。

使用 yt-dlp 的 `default` 依赖组和 Node.js / Deno JavaScript 运行时。录播支持已实现，直播与未开播内容会明确拒绝。网络或站点认证失败会报错，不能当成“无字幕”悄悄转入 ASR。在线链接、cookies 或 PO Token 的站点特定要求仍可能导致获取失败。已用 19 秒的公开视频完成“链接解析 → 字幕下载 → 视频下载 → SRT 输出”验证；不代表所有受限视频都能获取。

2026-09-14 用 [24 分钟的英文自动字幕视频](https://www.youtube.com/watch?v=ENFyTlno5bQ)复测：修复 FFmpeg 保留自动字幕空白占位行、导致 SRT 被误判为损坏的问题后，完整获取 1,225 条平台字幕；复用已下载视频，Vulkan 本地 ASR 也完整生成 242 条字幕。本次实测覆盖原字幕获取和整段识别，未调用中文翻译模型；平台滚动字幕的原文本和时间轴保留。

## 安装与启动

```bash
python3 scripts/setup_video.py
.venv/bin/python launch_app.py --video
```

也可在 `--video` 后附加本地路径或 YouTube 链接。系统需要 PyQt6、FFmpeg/ffprobe、Node.js 22+ 或 Deno，以及所选播放器；SubHD 浏览器保存在 `runtime/browsers/`。本地 ASR 仍使用原有 FunASR 安装流程和设备页面的 Vulkan / CPU 选择。

## 验证记录

翻译英文字幕后，播放和保存默认选择中英对照版本（中文在上、英文在下），恢复缓存时也默认使用双语。可在字幕版本列表切换为仅中文或原文；直接加载已有字幕时保留文件内容。

- 使用用户飞牛挂载中的《怪奇物语》S02E01：探测到英 / 意音轨及文本字幕，提取英文 SRT 共 579 条。
- 应用实际从 SubHD 获取该集 NF WEBRip 双语 ASS，转换为 601 条 SRT；以当前 NF WEB-DL 文件的英文字幕为参考，自动估计偏移 `+0.08s`、倍率 `1.0`。没有修改 NAS 原文件，未进行整集人工听校。
- 应用的 SubHD 搜索实际返回 8 个 S02E01 相关条目，包含上述已下载字幕。
- 合成语音验证了 ASR 带时间戳输出；Vulkan GPU 的 SRT 输出也单独验证。
- 合成字幕偏移 4 秒后自动恢复，测试样本的起点残差为 0 毫秒。
- 使用已登录的文本服务实际翻译 6 条英文字幕，返回编号完整，全部起止时间保持不变。
- 自动测试覆盖 SRT 解析与编码、文本字幕压缩包边界、时间变换、批量翻译编号校验和续做、真实 Qt 工作进程、缓存恢复、mpv 加载与跳转，以及现有实时字幕回归。

缓存中含字幕和可能下载的媒体，可以用页面里的 **打开字幕缓存目录** 查看，或在 **播放与保存 → 删除缓存…** 中选择当前视频或全部视频，分别删除字幕缓存、已下载的 YouTube 视频或识别音轨。删除字幕缓存包含翻译与 ASR 续做进度，但保留下载的媒体；删除视频保留字幕。确认删除会关闭当前播放器，任务运行期间不能删除。本地原视频、缓存目录外的原字幕和导出的字幕不会被删除。不同准备参数各自保存版本；翻译缓存不保存 API Key，停止任务会保留已完成的翻译批次和 ASR 分块。
