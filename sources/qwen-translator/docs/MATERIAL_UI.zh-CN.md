# 三端统一界面

本次采用 Material 3 风格的轻量、平面控件与明确选中态。桌面使用 PyQt6 Widgets 实现 Material 风格，安卓使用 Compose Material 3 / Media3。三端共享设计令牌；此次保留原生功能，不迁移 WebView 或整套 QML。

## 设计依据

使用者在会议中阅读双语字幕，或在手机、平板上管理视频并观看。设计领域是对话、转写、译文、字幕、片库和离线观看。视觉来自字幕纸张的白、文字墨色、播放器石墨、选择标记蓝与任务就绪绿。

辨识元素是原文与译文的成对阅读、视频与字幕的独立进度，以及始终一致的导航选中态。用平面阅读面板、按需显示的操作和明确文字状态取代大面积渐变、装饰数据卡和只有颜色的状态提示。

意图：让经常阅读字幕和管理视频的人迅速找到内容与下一步操作，像 Material 控件一样安静、清楚。
配色：云白 / 石墨为阅读面，蓝色只强调主操作与选中项；就绪、等待和失败有独立文字与语义颜色。
层次：采用边框与小幅底色变化；不使用层叠阴影。
表面：背景、内容、输入区三层；侧栏与画布保持同一色温。
字体：中文优先 Noto Sans CJK SC，安卓用系统无衬线；普通正文不使用等宽字体，标识符与耗时可使用等宽字。
间距：4 为基准，8 / 12 / 16 / 24 / 32；圆角 8 / 12 / 16 / 28。

## 唯一颜色来源

编辑 `design/material-theme.json` 后运行：

```sh
python3 scripts/sync_ui_theme.py
python3 scripts/sync_ui_theme.py --check
```

生成的 `ui_tokens.py` 与 `MaterialTokens.kt` 同时供桌面和安卓使用。手机与平板共用安卓主题和基础控件，无需分别维护两套颜色。

## 布局规则

| 环境 | 导航 | 内容 | 点击区域 |
| --- | --- | --- | --- |
| 手机 / 窄分屏 | 底部导航 | 单栏、操作按可用宽度换行 | 最小 48dp |
| 平板中等宽度 | 80dp 导航栏 | 居中阅读区 | 最小 48dp |
| 平板宽屏 | 216dp 侧栏 | 任务列表 / 详情分栏，播放器 / 设置分栏 | 最小 48dp |
| 电脑 | 完整侧栏，窄窗口收起文字 | 可拖动字幕分栏 | 键盘焦点与快捷键 |

在窗口尺寸而不是设备型号上决定布局，支持横竖屏、分屏与较大系统字体。保留已有下载、字幕翻译、清理确认、离线播放及密钥库行为。

## 验证边界

Qt 使用离屏真实控件检查主题、导航、窗口缩放与工作进程交互。安卓运行编译、单元测试和 Lint。未连接设备时不把构建成功描述为真机验收；涉及 NAS、下载和翻译的实时测试仍需显式运行。

## 手机实现

底部 Material 导航保留四个入口；顶栏可直接进入连接与外观设置。任务记录增加关键词与编号搜索、全部 / 进行中 / 已完成 / 需处理筛选。视频已就绪但字幕仍在处理时，任务仍归为进行中；无字幕而跳过处理的视频可归为已完成。卡片与离线片库的操作可自动换行，避免窄屏和大字号挤压按钮。筛选仅改变显示，不调整后台队列。

## 平板实现

按实时可用窗口宽度切换导航：小于 600dp 使用底部导航，600–839dp 使用导航栏，840dp 起使用完整侧栏。内容区至少 900×520dp 时，任务页切换为列表 / 详情，可拖动分隔线或用方向键调整宽度，Home 恢复默认值，屏幕阅读器可调整比例；窄分屏及高度不足时恢复单栏。任务选择、输入与列表滚动位置在布局切换时保留。

NAS 片库按 300dp 最小卡片宽度自适应排列。连接设置限制阅读宽度。宽屏播放器将画面与字幕 / 倍速设置并列，窄屏继续上下排列；原播放器、播放位置及字幕选择行为保留。
