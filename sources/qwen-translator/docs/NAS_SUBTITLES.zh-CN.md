# NAS 影视自动字幕

原生应用侧栏 **NAS 自动字幕**：从 Radarr / Sonarr 读取已经导入媒体库的最终文件，优先利用现有中文与匹配的网站字幕，随后使用英文外挂、内嵌英文文本字幕或本机 ASR，生成外挂字幕后回写视频同目录。

**最终字幕必选中英对照：`视频名.bilingual.srt`，中文在上、英文在下。** 默认还额外生成 `视频名.zh.srt`。例如：

```srt
1
00:00:01,200 --> 00:00:03,800
欢迎回来。
Welcome back.

2
00:00:04,000 --> 00:00:06,100
我们准备好了。
We are ready.
```

两行共用同一条编号、开始和结束时间。仅有中文时继续补英文原文；缺少英文音轨、字幕或无法可靠配对时进入 **待人工选择字幕**，不把纯中文字幕当作双语任务完成，也不发布纯中文成品来冒充最终结果。

此功能只读视频，只新增或按明确设置更新外挂字幕。不会改写、封装、烧录、移动或重命名视频，不影响硬链接和继续做种。原手动视频字幕、YouTube、网页翻译及实时同传入口保留。

## 启动与首次连接

```bash
cd /home/zhu/Projects/qwen-translator
.venv/bin/python launch_app.py --nas
```

1. 在 **偏好设置** 选择现有 Codex、Antigravity 或兼容 API、模型和翻译并发；在 **设备与音频** 选择现有 ASR 后端。NAS 不另建模型配置。
2. 填写 Radarr / Sonarr 地址和各自 API Key，点击 **保存 Key / 测试连接**。默认地址分别为 `http://192.168.1.100:7878` 和 `http://192.168.1.100:8989`。API Key 可在服务的 Settings → General 中查看。
3. 填写并测试路径映射，见下一节。本机目录默认留空，不能直接把 NAS 的 `/vol1/...` 或容器路径拼在 `/mnt/feiniu` 后面。
4. 保持 **自动处理新入库 / 升级文件** 关闭，启用 **后台同步**，点击 **保存并立即同步**。每个服务第一次成功同步只建立清单，即使预先打开自动开关，也不会翻译首次看到的库存。
5. 选中一个已入库测试视频，点 **处理所选影片**。确认其双语内容与写回结果后，再打开自动处理。多选支持 Ctrl / Shift。

应用启动时补同步；成功取得该服务清单后才恢复其任务。默认间隔 300 秒，可设为 30–86400 秒。关闭窗口会停止后台与子任务，重新打开后从本机队列、ASR 分块和翻译检查点续做。关闭应用期间没有独立守护进程。

默认一次处理一个视频；视频内部仍使用偏好设置里的翻译并发（默认 4，最高 8）。NAS 和手动视频准备共用进程锁，避免并行启动两个视频 ASR。手动视频或实时会话运行时，不启动新的 NAS 视频任务。

## 路径映射与实际挂载

已知服务路径来自部署说明：

| 服务 | API 路径前缀 | NAS 实际目录 | 已验证的本机 SMB 目录 |
| --- | --- | --- | --- |
| Radarr | `/var/apps/transmission/shares/transmission/media/movies` | `/vol1/@appshare/transmission/media/movies` | `/mnt/feiniu-smb/media-library/movies` |
| Sonarr | `/var/apps/transmission/shares/transmission/media/tv` | `/vol1/@appshare/transmission/media/tv` | `/mnt/feiniu-smb/media-library/tv` |

对应的 **本机目录必须是实际挂载中可读到同一批文件的位置**。例如，只有亲自确认某个挂载目录就是电影库之后，才把它填为 Radarr 的本机目录；路径前缀按目录边界匹配，不会把 `movies2` 当成 `movies`。禁止 `..` 越界及指向映射目录外的符号链接。

点击 **测试映射读取 / 临时文件 / 重命名** 后，后台会：

- 验证目录可读，记录实际挂载根、文件系统类型与来源。
- 使用随机命名的隐藏临时文件测试创建、关闭后回读、无覆盖重命名及替换行为，然后清理测试文件。
- 显示可读 / 可写结果。只读目录仍可用于本机生成，写回阶段会等待。

改变本机目录或远端前缀后需要重新测试。挂载来源变化或掉线后落回普通本机空目录时不会继续写入。正式回写还会在视频所在的实际子目录再测一次，避免根目录可写、影片子目录不可写的情况。

默认要求 NAS 挂载。仅在使用真实本机目录做测试时取消这一要求。源码中的无覆盖发布依赖 Linux `renameat2(RENAME_NOREPLACE)`；如果具体挂载不支持，任务进入等待写回，不退回直接复制最终文件的方式。

## 字幕来源与下载优先

按如下顺序处理：

1. 复用已有可用中文字幕，包括同名外挂、已有双语或内嵌中文文本字幕，记录来源。已有中文不重复调用翻译模型。
2. 默认尝试 **SubHD** 搜索与下载；可切换为 **ASSRT**，或关闭网站搜索。复用现有 `subtitle_sources.py` 和 SubHD 浏览器下载逻辑。
3. 网站没有结果时，使用匹配的英文外挂字幕。
4. 没有合适外挂时提取内嵌英文文本字幕。
5. 确认没有可用文本字幕后，使用现有本地 ASR，随后翻译。

图像字幕（PGS、VobSub 等）不作为文本字幕。探测、目录读取、字幕读取或解析失败会显示等待 / 人工处理，不会被伪装成“无字幕”然后启动 ASR。

已有纯中文时，会寻找可配对的英文文本，必要时用英文音轨 ASR 补充原文；配对要求每条中文字幕都找到可靠时间重叠的英文。无法配对时可在现有视频页校准，或手工选择匹配英文 / 双语字幕。不会用复制中文、空英文或无可靠对应关系的条目生成所谓双语。

### 自动匹配与人工选择

字幕网站通常不能保证只凭片名和季集准确匹配剪辑版本。当前自动采用要求：搜索结果能唯一对应 API 文件名、sceneName 或 originalFilePath 中带片源信息的完整发布名称，下载包中也能确定对应文本文件。大小写和常见分隔符可以规范化，但 `WEB-DL` / `BluRay`、发布组或季集不同不会被当成相同版本。仅片名、年份、`S01E01` 或“同为 1080p”不够。

结果含多个可能版本、整季包、无法确认具体文件，或网站要求登录 / 验证时，队列显示 **待人工选择字幕**。可以：

- 在队列表下方选择候选条目或下载后的具体字幕，点 **采用所选候选 / 文件**。
- 点击 **打开现有视频字幕页**，沿用搜索、浏览网站、下载、ZIP 导入和校准功能；候选条目与已下载文件会带入该页。
- 下载并核对后，回 NAS 页 **指定下载好的字幕**。
- 明确选择 **继续本地字幕 / ASR 兜底**，跳过该任务的网站查询。

### 视频页完成后回传

从 NAS 页点 **打开现有视频字幕页** 时，会带入对应任务并勾选 **字幕完成后回传到 NAS**。在视频页完成识别、翻译后，中文与对照成品会接回原任务，继续原有的版本检查、防覆盖发布和回读校验，不会重新识别或翻译。独立打开视频时，也可自行勾选此项。

以前已经在电脑生成的成品，可从缓存列表打开，再点 **回传当前成品到 NAS**。只接受能唯一对应已同步媒体清单、路径映射已验证且缓存对应当前视频版本的完整对照字幕。NAS 开关关闭或整个队列暂停时，会保留已接回的成品并提示开启 / 继续；后台恢复后自动写回。失败、冲突和成功状态会显示在视频页及 NAS 队列。

回传先复制成品到 NAS 任务自己的本机缓存；之后清理视频页缓存不会丢失待写回文件。暂停 / 取消的任务需先在 NAS 页继续，不会被回传操作自动恢复。已有人工字幕仍不覆盖，写回成功也仅表示文件已回读核对，飞牛加载与播放需另行验证。

不会绕过网站验证。ASSRT Token 仍在原视频字幕页通过系统密钥库保存；NAS 自动读取同一项凭据。没有 Token 时会提示人工处理，不把认证失败当成空搜索结果。

## 时间轴、翻译与最终输出

**保留匹配字幕时间轴** 是默认选项；也可选择自动或分段对齐，沿用已有英文内嵌参考 / 音轨语音活动校准。原始字幕、本机时间轴调整版和生成结果分别保留。

英文按现有编号批次翻译，校验返回编号、条数、重复项和解析结果；错误批次自动拆分重试，已成功批次立即保存。译文保持原文每条起止时间，双语输出为同一条中的上中文、下英文。编号或有效文本异常的源 SRT 会先停止要求检查。

输出文件：

| 文件 | 用途 |
| --- | --- |
| `视频名.bilingual.srt` | 必选的最终中英对照字幕；原视频页打开结果时默认选择双语 |
| `视频名.zh.srt` | 可选的独立中文版本，默认额外生成 |

只有双语成品完整校验后，任务才进入 **字幕已生成**，随后进入写回阶段。NAS 目录的最终名称不参与识别或翻译过程。

## 文件保护与写回恢复

每个任务绑定服务实例、媒体文件 ID、API 文件版本和处理配置。Sonarr 按 `episodeFileId` 合并多集共用文件。重复同步及重复选中相同配置不会生成重复任务。影片升级、文件 ID / 导入版本变化时会使旧任务失效，新版本重新判断。

NAS 任务还会在处理前、生成后和回写前完整读取视频并计算 SHA-256，确认内容与文件大小、修改时间。这样即使文件名、长度、修改时间都相同，内容替换也不会复用旧结果。完整读取会增加 NAS 网络流量，长电影在“读取校验”阶段等待较久属于正常现象。回写暂存后还会复查文件状态，避免生成期间替换视频。

旧版本的受管字幕及此前记录过版本关系的原字幕不会被自动当作新版字幕。文件未变而需要改用另一个模型、对齐方式或输出设置时，重新 **处理所选影片** 以建立相应配置的任务；暂停 / 继续则保留入队时的模型配置。

默认保护已有人工字幕：

- 同名文件不属于本软件时不覆盖，显示 **同名字幕冲突**。
- 正在复用的人工中文字幕与目标内容语义一致时保留原文件，包括编码和格式；不会因此宣称该文件以后可被本软件覆盖。
- 只有本机归属记录确认属于本软件、内容哈希没有被外部修改，且勾选 **允许更新本软件管理且未被外部修改的旧输出** 后，才会更新。勾选后点 **继续 / 重试** 可用现有本机结果重试写回。
- 外部编辑过的受管字幕也视为冲突。处理冲突可在视频页另存生成结果，人工整理后再重试；没有“强制覆盖人工字幕”按钮。

正式写入先使用视频目录内的隐藏临时文件，关闭并回读校验后才无覆盖重命名为最终名称。更新旧受管输出时，先保留隐藏备份并检查被移走的旧文件，再发布新字幕；遇到竞争创建 / 外部编辑保留文件并报告冲突。中断后的发布日志可恢复“已重命名但尚未确认”的情况，不需要再次翻译。

两个字幕文件分别发布，每一个最终名称都只对应完整文件。取消发生在两次发布之间时，可能已经存在其中一个完整字幕；不会撤回已经写好的成品。异常退出可能留下本软件命名的隐藏临时文件 / 更新备份，恢复同一任务会处理可确认归属的记录；无法确认的备份保留供人工检查，不猜测删除。

NAS 掉线、只读、写入或回读失败时，完成的结果保留在电脑，任务进入 **等待写回**，约 60 秒后重试。写回重试不重新翻译；重新映射目录也不会默默把旧结果发布给其他视频，必须重新确认媒体身份。

## 队列状态与控制

| 状态 | 含义 / 操作 |
| --- | --- |
| 仅入库清单 | 未排队；选择后处理 |
| 等待处理 / 处理中 | 单视频队列；显示字幕来源、阶段和进度 |
| 等待读取 / 网络 | 保留检查点，定时重试；检查映射、挂载或连接 |
| 待人工选择字幕 | 核对网站版本、具体文件、英文原文或时间轴；也可明确跳过网站 |
| 字幕已生成 | 完整双语结果在电脑，尚未确认写回 |
| 等待写回 | 本机成品保留；修复可写挂载后继续 |
| 同名字幕冲突 | 人工或外部修改文件受到保护 |
| 已写回 NAS · 未验证加载 | 已完成目标文件回读；**不是飞牛扫描 / 播放验证成功** |
| 已暂停 / 已取消 | 不自动重启；选择后点继续 / 重试 |
| 文件版本已更新 / 服务已无此文件 | 旧任务停止；查看当前入库版本 |

暂停、取消和重试可作用于所选任务；**暂停整个队列** 会持久保留。同步仍可更新清单。同步失败不会删除旧清单，只有完整成功的 API 快照才标记已无此文件。

## 本机数据与凭据

- `nas-cache/queue.sqlite3`：媒体清单、队列、配置快照、源字幕版本关系及输出归属 / 发布日志。SQLite 使用 WAL 与 FULL 同步。不要把它放到 NAS 挂载上。
- `nas-cache/videos/<版本与内容标识>/`：检查结果、下载字幕、ASR / 翻译检查点和完整 SRT。沿用原视频处理模块的缓存格式，增加 NAS 版本隔离。
- QSettings 的 `nas/config`：地址、映射及经过验证的挂载身份、自动开关、输出选项等普通设置。
- Radarr / Sonarr API Key：仅系统密钥库，按服务类型与地址隔离；请求使用 `X-Api-Key`，拒绝认证请求重定向。翻译 API Key / ASSRT Token 也不存队列、缓存或普通设置。

`nas-cache/` 已加入 `.gitignore`。保存任务恢复能力时应同时保留队列和对应本机缓存；删除归属记录后，已有 NAS 输出会按非受管文件保护，不能再自动更新。没有 NAS 常驻服务，也没有修改 Radarr、Sonarr、Transmission 或飞牛设置。
