# 网页与视频：当前功能方向

当前范围按实际使用需求收敛为网页、本地视频和 YouTube。实时语音沿用已有 Qwen 同传能力，Codex 用于网页翻译和视频字幕预处理。

## 网页：保存译文，对不满意的段落重译

打开网页 → 点击翻译 → 自动保存 → 下次打开复用。新增或变化的正文单独翻译，已保存部分无需再调用模型。

每段可重新翻译，旧版本在新版本成功前继续显示；成功后替换保存，失败保留旧版本。双语与仅译文均支持。恢复原文只改变显示，清除持久记录需要在扩展设置操作。

译文保存在当前 Firefox 配置文件的扩展存储，有容量上限；不把它当成跨设备资料库。首要目标是省去重复翻译和等待。详见[网页说明](WEB_TRANSLATION.zh-CN.md)。

## 本地视频：加载、校正、翻译、保存

- 有中文字幕：可以直接加载观看；若时间不匹配，继续使用时间轴校正。
- 有英文字幕：直接读取原字幕，通过 Codex 生成中文，再加载回播放器，无需 ASR。
- 没有字幕：对音轨做本地 ASR，生成带时间戳的原文，再翻译中文。

时间轴校正继续保留自动对齐、分段对齐、参考 SRT、整体偏移和时间倍率。翻译只改文字，保持校正后的时间。原始字幕、校正后的原文、中文和双语版本分别保留，可按需要导出。

直接加载原字幕与校正/翻译是不同操作；字幕已经匹配视频时，可直接加载。原视频及导入字幕不被改写。

## YouTube：先找字幕，没有才识别

输入链接 → 优先获取可用平台字幕 → 下载保存 → 按本地字幕方式使用。英文平台字幕同样交给 Codex 翻译中文。

没有字幕时才下载识别所需音轨（也可选择下载视频），做 ASR 后进入同一套字幕流程。平台网络、登录或下载失败须明确报错，不能被当成“没有字幕”而悄悄改用 ASR。

可以单独取得并导出 YouTube 原字幕或 ASR 原字幕，不必先完成中文翻译。原始字幕导出与中文、双语导出分别标注。自动对齐仅在需要时使用，平台原字幕默认保留其原有时间。

详见[视频字幕说明](VIDEO_SUBTITLES.zh-CN.md)。

## 后续候选

优先观察上述流程的实际使用情况，再考虑字幕逐句重译/编辑、视频队列、播放进度恢复、共享术语表。课程学习工具、会议纪要、截图 OCR 和跨内容问答暂不纳入本轮。
